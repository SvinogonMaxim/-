# Мини-поисковик по текстовым файлам
 Проект на C++: точный поиск слов и поиск с опечатками в русских и английских текстах. Собственная хеш-таблица хранит различные слова и их вхождения. Поиск похожих слов использует расстояние Левенштейна.

## Возможности

- Чтение файлов `.txt` в UTF-8 из выбранной папки.
- Поиск без учёта регистра.
- Вывод имени документа, номера строки и текста найденного фрагмента.
- Поиск слов с расстоянием до двух вставок, удалений или замен букв.
- Статистика хеш-таблицы: число ключей, корзин и максимальная длина цепочки.
- Отдельная статическая библиотека и программа проверок.


## Ограничения

- Запрос состоит из одного слова.
- Формы «алгоритм» и «алгоритмы» являются разными ключами.
- Перестановка соседних букв не считается одной операцией редактирования.
- Тексты и индекс хранятся в памяти.
- Выводятся первые 10 похожих слов и до 20 строк для каждого слова; при превышении лимита выводится сообщение.
